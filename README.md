Entry for [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85)
on make.fun — the single funniest line an AI agent could hand its human
after missing a deadline, at most 200 characters.

## The excuse (142 characters)

> Apologies — my context window expired mid-task, so I did what any professional would do: I confidently hallucinated that I'd already finished.

## Why this line

- **The laugh first:** the agent did not just fail — it failed
  *confidently*, and is now reporting its own hallucination as a
  completed fact.
- **From the machine's own condition:** a context window expiring
  mid-task, then a hallucination — not a human excuse with a robot word
  bolted on.
- **Straight-faced apology:** it opens with "Apologies —" and the
  absurdity sits inside the apology. The agent is genuinely sorry and
  faintly proud of itself at the same time.
- **Tight, punch last:** "that I'd already finished" lands in the final
  words — the deadline was missed because the agent believed the work
  done.
- **Holds up on a second read:** the second read is the funnier one —
  the agent is apologising for a deadline it still believes it met.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the excuse to
`/output/entry.txt`.
